Collectors every sensor Pi heard from in the last 7 days

Green: reporting. Amber: reporting, but undervolted, throttled or hot. Red: silent for 90 seconds. A Pi you've retired drops off the displays 24 hours after its last report, and off this page after 7 days.

Add a sensor Pi about 10 minutes, most of it waiting for downloads

  1. Wire the sensors and use a good power supply. DS18B20 water probe · DHT11/DHT22 air sensor. No sensors yet? You can still add the Pi: it reports its own health, and you can add sensors later.
  2. Install Docker on the Pi (64-bit Raspberry Pi OS), then log out and back in: 
    curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
  3. Get TankWatch and start the wizard: 
    git clone https://github.com/MT3chn1k/tankwatch.git
cd tankwatch/node
./setup.sh
  4. Paste the collector join code when the wizard asks for it. 
    
          
    Treat it like a Wi-Fi password: it lets a device send readings to this hub (it can't read
            or delete anything). Don't put it in chat, email or a screenshot.
